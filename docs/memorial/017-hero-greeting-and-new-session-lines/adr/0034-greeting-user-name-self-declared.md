# ADR-0034 — 用户名：用户自填；姜晓台词仍称「大人」

状态：已接受（待实施）
日期：2026-09-03
关联：ADR-0033（开槽）、ADR-0036（存 localStorage）、memorial 017

## 背景

问候语要带用户名（「上午好，{name}，有什么需要我搞定的么？」），但**整个 deepseek-harness 生态里不存在"用户名"这个概念**：

- `packages/identity/anonymous-user-id` 只提供匿名 UUID（`$DSH_HOME/.anonymous-user-id`），其 README 明确写着「不要用���来识别用户」；
- client 侧无账号 / 登录 / profile，无 `userName` 或 `displayName`（同名标识符全是 LLM provider 的显示名，无关）。

所以名字必须从零引入，来源是一个真决策。

## 决策

### 1. 用户名由用户自己填，不是推断出来的

新增设置项，落 client 侧 localStorage（存储机制见 ADR-0036）。空值 = 未填，走退化文案。

### 2. 未填名字时：去掉名字与逗号，保留问候语本身

「上午好，有什么需要我搞定的么？」——不带名版本与带名版本是**两套完整文案**，不跨文案 key 拼接句子（i18n 硬约束）。这样装上插件、还没填名字也能立刻看到效果。

### 3. 姜晓的台词一律称「大人」，不带用户名

用户名只出现在 hero 大标题，不进姜晓的台词气泡。理由：

- 姜晓全部现有台词（8 条状态 + 4 条惊吓）一律用「大人」，人设是「古风·贵族·剑士·冷冽」（`docs/character-profile.md`），`docs/character-lines.md` 要求古风敬语；
- 一个现代用户名塞进半文半白的句子会破人设；
- 大标题已经叫过一次名字，气泡里再叫一遍是重复。

### 4. 校验

`trim` 后非空才算有效（全空白 = 未填）；上限 **16 字符**；剥离控制字符与换行（防止破坏单行 headline 排版）；允许中文 / 字母 / emoji；不做敏感词校验。

## 被否决的替代方案

1. **从操作系统用户名推断**（`os.userInfo().username`）——零交互零配置，但拿到的是 `jxc123` 这类机器账号名，「上午好，jxc123」的关怀感是负的；Windows 域账号 / 中文用户名难处理；且属未经同意把系统信息摆到界面上。否决。
2. **首次启动时问一次**——零配置负担，但多一个冷启动模态，打断"打开就能用"，还要处理重设入口。否决。
3. **不做名字，只做时段问候**——改动最小，但抽掉了用户诉求的核心（被叫名字）。否决。
4. **未填名字时回落原文案「探索未至之境」**——语义上是"没配置 = 没启用"，但用户装了插件却因没填名字而完全看不到变化，等于白装。否决。
5. **用通用称呼兜底「上午好，朋友」**——只需一套文案，但中文产品里「朋友」偏运营腔，与产品克制气质冲突。否决。
