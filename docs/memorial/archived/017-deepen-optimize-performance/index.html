H3素材路由：304 路径仍全量 readFile，且无压缩 / 无内存缓存
性能高已核实
现象
await Promise.all([readFile(filePath), stat(filePath)]) 位于 if-none-match 判定之前——条件请求命中 304 前已把整个文件读进内存；响应头无 content-encoding；全文件无内存缓存。对 MB 级素材尤其昂贵。
证据
asset-routes.ts:91（readFile 在 :97 ETag 判定之前）asset-routes.ts:102-106（无 content-encoding）
建议
① 先 stat 算 ETag，if-none-match 命中直接 304 返回、不读文件；② 按 path + mtimeMs 做 LRU 字节缓存；③ 网关层 brotli/gzip（收益主要在 woff2/png，需实测）。
收益
中-高（取决于 304 命中率）。
风险
低——但方向不可逆。
前车之鉴（务必先读）：asset-routes.ts:87-90 记录了「曾用 immutable, max-age=86400 强缓存导致浏览器最长 24h 看不到新字节（2026-08-22 白偏红修复踩坑）」——不可回退到强缓存。
