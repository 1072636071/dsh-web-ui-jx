# ADR-0013 — 多动作变体：一次性播放列表拼接与随机不重复调度

## 状态

已接受（memorial 008 定案，实施中）。

## 背景

工作/待机这类长驻状态只有一个循环动作，长期观看单调（memorial 008 诉求 B）。并行驻留 working（ADR-0010）会放大这个问题。需要每态多个动作可轮换，且动作之间过渡合理。

既有事实：过渡段「播一遍 + 按真实时长推进」机制已存在（webp-duration）；摸鱼彩蛋/并行驻留/poke 等运行期覆盖机制已存在（ADR-0010/0011）。

## 决策

1. **覆盖范围**：仅待机（idle）与工作（working）两个长驻态；「状态 → 变体列表」配置驱动，支持后续扩态补素材即可。
2. **共用中性帧约定**：同一状态所有变体素材形状为「中性姿态 → 动作 → 中性姿态」，首尾帧 = 该状态主素材第一帧（过渡段落下的姿态）。中性帧参考图由主素材第一帧导出，供生成工具做首帧 conditioning。
3. **拼接机制**：变体素材只播一遍（`loops=1`），运行期把随机抽取的变体串成无限播放列表，复用「播一遍 + 按真实时长推进」机制；段间在中性帧停顿 ~400ms，像素级残差（发丝相位/色调）借停顿读作自然微动。
4. **调度**：随机抽取、不连续重复；随机源可注入（测试可控）。主素材作为「基础」候选入池。
5. **打断语义**：摸鱼彩蛋/poke/紧急态/状态切换打断时丢弃播放列表位置，回落后重新随机抽取（不续播半截）。
6. **轮换开关**：SettingsCard「角色」section 新增开关，默认开启，持久化同既有设置键模式。
7. **素材供给与转码**：用户供绿幕视频，实施方转码（去绿幕 + 水印擦除 + 67ms/帧 + 360×640 + 一次性 webp）；三道质检门：工作变体符咒全程在场、局部突变扫描、首尾帧 vs 中性帧复验。

## 被否决的替代

- **无限循环 + 循环边界定时换源**：变体保持 `loops=0`，按解析时长估边界换 src。定时器与帧边界有 ±数十毫秒漂移（切点可能偏一帧），src 重载有闪白风险。
- **交叉淡化常态化**：复用焦点切换的双层 img 淡入淡出。淡化期间角色重影，频繁切换观感差；仅保留为兜底手段。
- **变体两两专用过渡素材**：最自然，但 N 变体需 N×(N-1) 过渡素材，成本平方级。
- **带权重随机 / 固定轮换**：每态仅 2–3 变体，权重配置收益低；固定轮换看两轮即识破，违背去单调初衷。
- **覆盖全部 13 循环态**：短驻留/紧急态收益极低，素材成本爆炸。

## 后果

- 素材制作侧新增「共用中性首尾帧」约定；生成工具若无法像素级保证，姿态级一致 + 段间停顿兜底（本次 9 段素材实测姿态级一致、像素级小残差，已验证该兜底成立）。
- 变体正式命名 `{state}-vN.webp`（主素材视为 v1），进 ADR-0003 的 `character/` webp 白名单。
- 运行期播放项新增「循环一次」类型，推进逻辑与过渡段共用同一时长解析链路。
