# ADR-0015 — 10 经典循环态全部烘焙正反倒放（重启突兀修复）

## 状态

已接受（memorial 008 实施后补充，用户实机反馈驱动）。

## 背景

ADR-0012 落地后实机复看，用户指出经典态仍有「重启突兀」：

- 突兀点定位 = **最后一帧跳回第一帧的瞬间有视觉跳变**。姿态层面首尾帧确实
  回到起点附近（首尾缝全帧均值 1.0–1.6，压缩噪声级），但**动作方向单调的
  素材（reading 单向翻页、working 单向画符等）在循环点处「运动速度瞬间
  反向」**，肉眼可辨——ADR-0012 Q1 的「10 经典态本质无缝、不需要倒放」
  结论只度量了姿态差，没有度量速度连续性，是盲区。
- 用户确认范围：除 reading 外，最开始画符的 working 同样明显；并确认
  「很多素材都是正反倒放才能循环」。
- 素材源项目（open-code-mm）的设计语言本身即如此：循环段按「首帧=尾帧=
  同图」生成闭合，过渡段一律「正放 + ffmpeg 倒放」成对入库。

## 决策

1. **10 经典态（idle/thinking/reading/replying/error/welcome/done/permission/
   listening/working）全部整段烘焙正反倒放**：`tools/anim_loop_repair.py`
   新增 `--pingpong-classic` 模式。与 REPAIRS 的 pingpong 不同——不裁头尾
   帧（经典态是真循环，无淡入残留/死定格），正放 + 倒放端点不重复，
   单圈 2n-2 帧 × 67ms：9 段 75→148 帧（9916ms）、working 86→170 帧
   （11390ms，先 splice 后 pingpong 的二次加工）。
2. **降采样沿用 ADR-0012 D2**：360×640 + 高质量重编码；原件备份 `bak/`
   （working 的真原件已在 splice 时备份，不覆盖）。
3. **运行期同步**：`variant-rotation.ts` 基础段时长由单常量 5025ms 改为
   按状态表 `{idle: 9916, working: 11390}`——轮换周期必须等于烘焙后单圈，
   否则切段落在动作中段，把要修的跳变从定时器再引进来。变体段与其余 8 态
   无时长耦合（`loops=0` 无限循环 / `loops=1` 单次播完），零改动。

## 被否决的替代

- **维持 ADR-0012 结论（仅修 3 表情 + working 局部）**：实测 reading/working
  重启跳变肉眼可见，否决。
- **仅对 reading/working 定向烘焙**：突兀感是「方向单调」的程度问题而非
  有无问题，其余 8 态同源同规格，统一烘焙保证观感一致，且一次脚本跑完
  边际成本低。
- **运行期倒放播放器 / 双素材切换**：同 ADR-0012 否决理由（依赖、闪断、
  定时漂移），不再重复。

## 后果

- 经典态单圈时长翻倍（≈5s→≈10s）：长驻状态动作节奏更慢更自然；轮换池里
  基础段出场周期变长，单调感进一步下降。
- 循环点两侧均为相邻帧，方向反转读作自然回返；过渡段↔循环态衔接不受影响
  （烘焙不改首帧，过渡段末帧仍精确对齐）。
- `webp-duration.test.ts` 真实素材回归值更新（9916/11390）；素材规格沉淀
  补充一条：**循环态验收除姿态缝外，还须审动作方向的速度连续性**。
