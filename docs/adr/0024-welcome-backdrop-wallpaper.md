# ADR-0024 — 欢迎背景整页壁纸层

## 状态

已接受（2026-08 grill 会话「欢迎图作本机背景」定案；待实施）。

## 背景

ADR-0023 移除 welcome 入场动画表演后，openCodeMM 侧的静态欢迎立绘（源文件 `E:\work\sp\openCodeMM\docs\image\欢迎16-9.png`，2560×1440，16:9，姜晓黑金和服满月夜景）需要新归宿：作为宿主 GUI 的整页背景图。现状是宿主页背景为纯色 surface——L2 只重映射颜色 token，全代码库（含参考项目 dsh-web-ui、DSH 宿主 apps/web）均无背景图层/壁纸先例，这是全新能力。用户需求三要素：图片随插件打包本机服务（不依赖外网）、作整页背景、可在设置卡关闭。

## 决策

**D1 — 整页视口壁纸层，WebP 随包本机服务**：

新增 fixed 全视口背景层（cover 缩放、pointer-events:none、层级垫于全部宿主内容与 FX 层之下）。素材转码为 `assets/welcome/welcome-16-9.webp`（约 200–500KB），经既有 `/api/dsh-jx/*` 素材路由本机服务。否决 PNG 原样入库（4.3MB 无谓增重发布包；原件留存 openCodeMM 源项目不丢失）；否决远程 URL 方案（用户明确要本机图）。

**D2 — 壁纸模式 = surface token 联动半透明**：

背景开启时，L2 的 `--jx-surface-*` 由不透明纯色切换为带 alpha 形态（实现取向：RGB 通道变量与 alpha 变量组合，或等价 color-mix 方案），使宿主面板透出背景；关闭时整体回退纯色不透明。半透明化由总开关统一驱动，不单独暴露「哪些面板透」的粒度。否决「仅边缘缝隙露出」与「整页低透明度淡影」两案——面板不动则背景几乎不可见，功能无意义。

**D3 — 双滑杆可调 + 总开关，归皮肤开关 section**：

设置卡「皮肤开关」section 内新增一组：「欢迎背景」总开关 +「壁纸不透明度」（图片层 alpha，默认约 85%）+「面板不透明度」（surface alpha，默认约 75%）两根连续滑杆（0–100%）。总开关关闭时两滑杆禁用置灰。持久化沿用 `localStorage('jx-*')` 范式（具体键名实施期定）。默认值以实机效果验收微调为准。压暗遮罩为固定调参不设滑杆（深色叠暗纱 / 浅色叠白纱），保证文字对比度下限。

**D4 — 深浅双主题都显示**：

墨金卷轴（深色）与宣纸梅花（浅色）都显示欢迎背景；浅色白纱遮罩参数独立调校。否决「仅深色生效、浅色自动隐藏」案（用户裁定深浅都显示）。

## 后果

- 设置卡皮肤 section 从单 toggle 变为「总开关 + 双滑杆」组，信息架构变化。
- L2 token 体系新增 alpha 维度：`--jx-surface-*` 需拆通道或引入组合机制；`DESIGN.md` 三层架构文档需同步补条目。
- 发布包增重 <500KB（对比 ADR-0023 减重 15MB，净影响可忽略）。
- 半透明面板下的文字对比度依赖遮罩浓度，验收阶段需实测深浅两主题可读性后固化参数。
- 关闭背景 = 回到现状（纯色 surface），无残留视觉痕迹；两滑杆值保留但禁用。
- 背景层为静态图无动效，无 reduced-motion 义务；z-index 必须低于角色浮层与全部 FX 层，且 pointer-events:none 不违反 ADR-0006 的穿透原则反转（该反转仅针对角色浮层本体）。
