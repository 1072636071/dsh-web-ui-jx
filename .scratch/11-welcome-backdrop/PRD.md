# PRD — 欢迎背景整页壁纸层（ADR-0024 D1–D4）

**Status**: resolved
**来源**: grill 会话「欢迎图作本机背景」定案（ADR-0024 已回写）；ADR-0023 移除 welcome 入场动画后，静态欢迎立绘需新归宿
**创建**: 2026-08-24

## 问题陈述

ADR-0023 移除 welcome 入场动画表演后，openCodeMM 侧静态欢迎立绘（2560×1440，16:9，姜晓黑金和服满月夜景）需要新归宿：作为宿主 GUI 的整页背景图。宿主页背景为纯色 surface，DOM 无背景图层/壁纸先例——这是全新能力。用户要求三要素：图片随插件打包本机服务（不依赖外网）、作整页背景、可在设置卡关闭。

背景壁纸层落地后实测暴露出**可见性问题**：壁纸图虽以 `z-index:-1` 垫底，但被宿主不透明画布背景盖住，整层不可见（「背景不生效」）。且浅色壁纸被深色实底 + 厚重暗纱压成一片灰，观感接近纯色。

## 解决方案

**D1 整页壁纸层**：body 直挂 fixed 全视口层（cover、pointer-events:none、垫于宿主内容之下），WebP 随包经 `/api/dsh-jx/*` 路由本机服务。

**D2 壁纸模式 = surface 联动半透明**：背景开启时写 `--jx-panel-alpha`，L2 的 `--jx-surface-*` 消费为带 alpha 形态，宿主面板透出壁纸；关闭整体回退纯色。

**D3 总开关 + 滑杆组**：设置卡皮肤 section 内「欢迎背景」总开关 + 连续滑杆，持久化沿用 `localStorage('jx-*')`。压暗纱浓度由固定调参改为**用户可调滑块**（本次新增）。

**D4 深浅双主题**：深色叠暗纱 / 浅色叠白纱，均显示；纱色按主题运行时注入。

**可见性修复**：背景层改为 `z-index:0`；base 层透明（壁纸已 cover 全屏）；宿主 html/body 画布在背景挂载时经 `:has` 透明化让壁纸透出（卸载即回落）；压暗纱浓度默认明显下调。

## 用户故事

1. 作为用户，我希望把欢迎立绘铺满整页作背景，以便界面有整体美感。
2. 作为用户，我希望面板透出壁纸（半透明），以便壁纸真正可见而非仅边缘缝隙露出。
3. 作为用户，我希望在设置卡一键关闭背景、并把壁纸/面板/压暗浓度度各自调到满意，以便不同光线与偏好下可读性可用。
4. 作为用户，我希望深浅两主题都显示背景，以便主题切换不丢背景。
