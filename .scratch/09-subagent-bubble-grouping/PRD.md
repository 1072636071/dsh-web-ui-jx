# PRD — 会话气泡列子代理归组（根祖先锚定折叠）

Status: ready-for-agent
来源: grill 会话（jxx-grill-with-docs，2026-08-22）+ ADR-0018 + DESIGN.md §4 + CONTEXT.md

## 问题陈述

DSH 宿主用户在跑多代理工作流（如 `/jxx-grill-with-docs` 这类会派生大量子代理
会话的任务）时，角色浮层左侧的会话气泡列会被子会话占满：并行子代理高频刷新、
在宿主列表中长期霸榜，气泡列常驻满上限（5 个）+「+N」，而真正重要的主会话气泡
反而被挤进折叠区。子会话和普通会话在气泡眼里毫无区别——气泡列没有层级概念，
用户既分不清哪条工作流产生了哪些子会话，也无法从一团同名气泡里找到主会话。

## 解决方案

会话气泡列升级为**归组模型**（ADR-0018）：一条主会话无论派生多少层子代理，
只占一个气泡。

- **归组**：所有 subagent 来源的会话沿父链向上折叠进其最顶层的普通会话祖先
  （根祖先）；徽标 `▸N` 显示该工作流的后代总数，有运行中后代时徽标前缀金色
  呼吸迷你点——不展开也能感知"下面还有活人在干"。
- **展开**：点击徽标原地展开该组的子气泡列表（向左缩进、弱化样式、带连接线，
  层级一眼可辨），再点收起；点击子气泡直接跳转对应子会话。
- **当前可见性**：当前打开的是某个子会话时，其根祖先气泡金描边且自动展开——
  当前会话永远在气泡列里看得见。
- **上限语义**：数量上限（默认 5，可配 1–10）只约束顶层归组气泡；展开的子列表
  不占名额；顶层溢出仍折叠为「+N」，行为与既有习惯一致。
- 非多代理场景体验完全不变：普通会话照旧各占一气泡，样式/动效/交互沿用 ADR-0007。

## 用户故事

1. 作为 DSH 宿主用户，我想要一条多代理工作流派生的所有子会话折叠进主会话的一个气泡，以便气泡列不再被子会话占满、主会话不再被挤出视野。
2. 作为 DSH 宿主用户，我想要归组气泡上显示后代总数徽标（`▸N`/`▾N`），以便知道这条工作流下有多少个子会话。
3. 作为 DSH 宿主用户，我想要存在运行中后代时徽标前缀金色呼吸迷你点，以便不展开就能感知子代理正在干活。
4. 作为 DSH 宿主用户，我想要点击徽标原地展开该组子气泡列表、再点收起，以便需要时直达某个子会话、不需要时收起保持素净。
5. 作为 DSH 宿主用户，我想要展开后的子气泡向左缩进并带弱化背景与连接线，以便一眼分辨父子层级。
6. 作为 DSH 宿主用户，我想要点击子气泡直接跳转到那个子会话，以便查看某个子代理的实际输出。
7. 作为 DSH 宿主用户，我当前打开的是某个子会话时，希望其根祖先气泡金描边且该组自动展开，以便我在气泡列里永远找得到当前位置。
8. 作为 DSH 宿主用户，我想要数量上限只约束顶层气泡、展开的子列表不占名额，以便浏览一组子会话时不把其他顶层气泡挤进折叠区。
9. 作为 DSH 宿主用户，我想要顶层气泡超过上限时仍然折叠为「+N」、点击原地展开，以便溢出行为与我已熟悉的习惯一致。
10. 作为 DSH 宿主用户，我想要运行中/已完成的状态点语义在父子两级都保留（金呼吸 = 运行中，石绿实心 = 跑完未查看），以便一眼区分每个会话的状态。
11. 作为 DSH 宿主用户，我想要普通非 subagent 会话照旧各占一个独立气泡，以便不用多代理工具时体验与从前完全一致。
12. 作为 DSH 宿主用户，我想要 fork 出来的分支会话不被当作任何会话的后代（自成气泡或自成根），以便我的分叉实验独立可见、不被卷进源会话的徽标计数。
13. 作为 DSH 宿主用户，即使某条父会话已经不在列表里，我也想让它遗留的子会话仍然显示（自成顶层气泡），以便导航入口不因孤儿状态丢失。
14. 作为 DSH 宿主用户，我想要会话开始运行/跑完/被删除时分组实时增减，以便气泡列始终反映真实会话状态。
15. 作为 DSH 宿主用户，我想要无任何 running/completed 会话时不显示气泡列，以便浮层保持素净。
16. 作为 DSH 宿主用户，我想要气泡与徽标出现 150ms 淡入 / 消失 100ms 淡出、`prefers-reduced-motion` 下全关，以便动效舒适且可访问。
17. 作为 DSH 宿主用户，我想要点击气泡或徽标不触发角色拖动，以便点击与拖动互不干扰。
18. 作为 DSH 宿主用户，我想要键盘（Tab + Enter/Space）也能操作气泡与徽标、读屏器能念出徽标的剩余子会话数，以便不依赖鼠标也可用。
19. 作为开发者，我想要谱系上溯、归组、徽标计数、强制展开、孤儿回退、排序全部收敛为一个纯函数（输入投影 → 输出分组结构），以便用 vitest node 环境单元测试（复用 session-bubbles 既有 seam，新 seam 数 = 0）。
20. 作为维护者，我想要 DESIGN.md §4 / CONTEXT.md / ADR-0018 与实现保持一致（已于 grill 会话完成文档侧），以便后续读者不被过时定义误导。

## 实现决策

1. **归组模型**：气泡列基本单元改为归组气泡 = 根祖先 + 其全部通过范围过滤
   （`running || completed`）的 subagent 后代。组的入选条件 = 根自身或任一后代
   通过过滤（根空闲而后代在跑 ⇒ 根气泡仍在，仅靠徽标呼吸点示意）。idle 后代
   不显示。无谱系字段的数据退化为旧行为（每会话一泡），完全向后兼容。
2. **根祖先锚定**：从任一会话沿 `parentId` 向上溯，停在第一个 `origin ≠
   'subagent'` 的会话。上溯中断（父行不在列表镜像中）或成环以停留节点为根；
   停留节点本身是 subagent 则自成顶层归组气泡（孤儿回退，D7）。普通 fork 截断
   谱系传播——fork 出的会话不是任何人的后代（宿主语义：fork 的 `origin` 非
   `'subagent'`）。
3. **子代理徽标**：箭头 + 后代总数，收起 `▸N` / 展开 `▾N`，置于父气泡标题右侧
   不换行不挤压；存在运行中后代时前缀金色呼吸迷你点（复用既有 `.dotRunning`
   视觉语义，reduced-motion 下静态）。否决双数字 `▸M/N`（宽度抖动）与 completed
   描绿三色态（信息密度超载，completed 后代展开后可见石绿点）（D4）。
4. **展开交互**：点击徽标切换该组展开/收起，阻断冒泡不触发跳转；挂
   `data-jx-interactive` 不触发整盒拖动（复用 ADR-0006 排除机制）。各组独立维护
   手动展开态；生效展开态 = 手动展开 或 当前会话在该组后代中（containsCurrent）
   ——后者保证当前会话永远可见，current 离开后自动回落手动状态（代价已接受：
   current 仍在组内时手动收起无效）（D5/D6）。
5. **子气泡呈现**：原地插在父气泡视觉上方（DOM 中位于父之后，配合列的
   column-reverse 自下而上生长）；相对父气泡向左缩进 12px（右缘对齐布局下的
   自然伸展方向）+ 弱化背景 + 左侧竖连接线；组内顺序按宿主列表原序（D5/D8）。
6. **上限语义**：maxVisible 只约束顶层归组气泡数；展开的子列表不占名额、不受限；
   全局「+N」MoreBubble 折叠机制不变（只管顶层溢出）；默认 5、范围 1–10、
   持久化 key 与配置模块均不变（D3）。
7. **current 传播**：isCurrent 向上传播——current 为某后代时其根祖先气泡挂金
   描边（子气泡本身若可见也各自保留高亮）（D6）。
8. **排序**：顶层组按根在宿主列表中的首次出现位次排列；不做时间戳重排（对齐
   官方 flattenLineage 先例的「永不重排 hydrated 列表」原则）（D8）。
9. **模块边界**：新增纯函数 `buildBubbleGroups()`（连同输入投影扩展——多投影
   `parentId`/`origin` 两字段）与既有过滤函数同住 session-bubbles 纯逻辑模块，
   与 SDK 类型解耦；组件层改造 SessionBubbleList 渲染分组结构；样式增补徽标 /
   子气泡 / 连接线；设置卡描述文案微调为「顶层归组气泡数」。不复用 SDK 的
   谱系聚合函数（其按每层祖先索引、输入为 SDK Record 形状，与本插件轻量投影
   不合；仅引为先例）（D8）。
10. **动效**：子气泡出现/消失复用既有 leaving 条目跟踪机制与 150/100ms 淡入淡出；
    reduced-motion 全关（D9）。
11. **数据源不变**：仍订阅宿主会话列表快照（ids + byId + current），只消费不改
    宿主接口；addressed breadcrumb-only 行、子代理目录 RPC 等路由机制均不涉及。

## 测试决策

- **好测试的定义**：只测外部行为——输入（含 parentId/origin 的投影条目、
  current、maxVisible）→ 输出（顶层分组序列、组内成员序、徽标计数 N 与运行中
  数、moreCount、isCurrent 及其向上传播、containsCurrent 强制展开标记）；不测
  DOM、类名、React 渲染、订阅时序等实现细节。
- **Seam：复用既有 seam**（session-bubbles 纯逻辑模块 + vitest node 环境，扩展现有
  session-bubbles 测试文件；先例 warp-controller / overlay-position / state-machine
  同款模式）。**新 seam 数 = 0**。
- **被测模块**：session-bubbles 纯逻辑（归组 + 过滤 + 折叠 + current 传播）。
  配置模块（localStorage）、DOM 薄壳（组件渲染、徽标点击、拖动排除、动画）不在
  自动化范围（对齐本仓库 skin/fx 无 localStorage 测试、组件无 DOM 测试惯例）。
- **覆盖清单**：
  - 平铺回归：无 parentId/origin 字段时输出与旧版逐条目等价（向后兼容护栏）。
  - 单层归组：多个 subagent 并入同一根，徽标总数与运行中数正确。
  - 多层嵌套：孙代及更深层并入根祖先（根锚定而非直接父锚定）。
  - fork 截断：fork 会话不成组、不计数。
  - 孤儿回退：父行缺失 / 父链成环 → 停留节点为根，subagent 孤儿自成顶层。
  - current 传播：current 为后代 → 根气泡高亮 + containsCurrent 为真；current
    为根本身 / 无 current / 不相关会话 → 不传播。
  - 上限只管顶层：展开组不影响 moreCount；顶层溢出折叠边界（≤max / max+1 / 大额）。
  - 排序：顶层按根首次出现位次；组内按原序；空列表 → 空。
- **不自动化部分**：分组渲染、徽标点击展开/收起、缩进视觉、连接线、呼吸动画、
  触屏点击、reduced-motion 表现——人工视觉验证，沿用浮层系统一贯惯例
  （05 号功能测试决策同款）。

## 超出范围

- **递归树形展示**：展开只平铺该组全部后代（一级缩进），不做多层嵌套再展开。
- **completed 子代的额外强提醒**（徽标三色态等）——已否决，见 ADR-0018 D4。
- **直接隐藏子会话 / 全平铺缩进树**两个方向——grill 已否决，见 ADR-0018 D1。
- **气泡内内容预览 / 进度条 / 状态文字**——本期仍是标题 + 点 + 徽标。
- **宿主接口与 SDK 变更**——纯消费端功能；子代理目录 RPC、openSubagent 地址
  路由等机制不涉及。
- **配置迁移**——上限数值范围、持久化 key、默认值均不变，仅描述文案微调。
- **台词气泡、焦点仲裁、状态机**等其他浮层子系统——并行关注点零接触。
