# 全素材切换统一淡入

**Status:** ready-for-agent

**Blocked by:** 02

**构建内容：** 角色画面的一切素材切换都柔和过渡——过渡段入场、过渡→循环落稳、待机变体轮换、工作轮换段间、焦点会话切换，统一 150ms 淡入淡出，不再出现硬切闪断。系统偏好减少动态效果时全部关闭。

**验收标准：**

- [ ] cross-fade 触发条件从焦点 nonce 变化扩展为播放项 url 任意变化：旧素材作底层淡出、新素材上层淡入，150ms
- [ ] 150ms 内连续再切时底层直接替换为最新旧帧；浮层盒内 img 恒 ≤2 的自愈守卫不变量保持
- [ ] prefers-reduced-motion 下淡入淡出全关（沿用现有守卫）
- [ ] 不在资产层烘焙淡入（循环回卷点不得有暗帧）
- [ ] 焦点切换原有行为不回退（含焦点 nonce 递增语义）
- [ ] 组件级测试覆盖：url 变化触发 underlay、连切替换、reduced-motion 禁用

## 评论

- 2026-08-23：决策依据 PRD 实现决策 9（D15）。实现复用 ADR-0008 决策 3 双 img underlay 机制，仅扩展触发条件。
