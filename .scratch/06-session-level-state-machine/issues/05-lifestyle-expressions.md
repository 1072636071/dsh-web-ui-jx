# 05 — 生活化表情意图

**Status:** ready-for-agent

**Blocked by:** 03, 04

**构建内容：** 角色有情绪反应：任务完成时露出开心表情；授权/工具等待 10 秒未处理时露出生气表情；被点击或拖动时惊吓一次（播完自动回位，拖动中不重复）。三个新表情与现有表情一起进入空闲随机点缀池。素材未就绪时表情意图自动降级为普通过渡，不报错、不中断播放。

**验收标准：**

- [ ] 会话完成（done）触发开心表情（「idle→开心→idle」）
- [ ] 授权/工具等待持续 10s 未响应触发开心之外的生气表情；响应后回位
- [ ] 点击角色触发一次惊吓表情，播完自动回到当前状态
- [ ] 拖动角色触发一次惊吓表情，拖动过程中不重复触发
- [ ] 三个新表情进入 idle 随机点缀池（与现有 6 表情混池）
- [ ] 生气计时为纯逻辑时间驱动（可注入时钟），复用既有 tick 先例
- [ ] 表情素材未就绪时（对应 webp 不可达）对应意图降级为普通过渡，无报错、播放链路完整
- [ ] 纯逻辑测试覆盖：三表情触发、10s 生气计时、惊吓去重、降级路径
- [ ] 通过 `npm run build` 与 `npm run verify`
