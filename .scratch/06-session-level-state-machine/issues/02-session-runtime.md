# 02 — 会话级状态机容器与焦点跟随

**Status:** resolved

**Blocked by:** 01

**构建内容：** 多会话并发运行互不干扰。每个会话有独立的状态与播放序列，后台会话的事件不会打断当前画面；用户切换打开会话时浮层跟随切换（150ms 淡入淡出），切回某会话时直接显示该会话当前状态；会话随宿主列表自动创建与清理，无泄漏。原单例状态机与"只跟当前会话"的逻辑被此机制吸收替换。

**验收标准：**

- [ ] 新纯逻辑模块（无 DOM/React）提供：会话注册/注销、每会话状态推进、焦点会话输出、订阅接口
- [ ] 会话状态推导复用既有差分机制（error > permission > working > replying > thinking > done > idle；reading 由 thinking 超时推导）
- [ ] 会话出现在列表时自动注册并挂订阅；从列表移除时销毁实例并释放全部订阅
- [ ] 浮层渲染焦点会话（当前打开会话）的播放序列；切换打开会话时跟随切换
- [ ] 焦点切换不播状态机过渡，直接切目标会话当前循环态 + 150ms 淡入淡出
- [ ] 切回已结束会话时显示其保留状态（如 done），不从头推导
- [ ] 原有单例状态机与"仅跟随当前会话"模块被替换移除，无残留双路径
- [ ] 纯逻辑测试沿袭既有状态机测试先例：输入事件/注册注销 → 断言焦点与会话 playback；时间驱动注入时钟
- [ ] 通过 `npm run build` 与 `npm run verify`
