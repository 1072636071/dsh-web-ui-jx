# 06 — 表情素材就位

**Status:** ready-for-agent

**Blocked by:** 05

**构建内容：** 6 个生活化表情素材入库并激活：`idle↔开心/生气/惊吓` 各 2 边 webp 放入角色素材目录（命名、规格与既有素材一致：alpha 透明、67ms 帧、末帧定格、画风对齐），素材就位后开心/生气/惊吓表情动画自动生效（无需代码改动，05 的降级路径自动切换为真实播放）。

**验收标准：**

- [ ] 6 个 webp 入库（idle↔happy/angry/shocked 各 2 边），命名符合 `transition-{from}-{to}` 规范
- [ ] 素材规格与既有素材一致（透明底、帧节奏、定格收尾、画风对齐）
- [ ] 素材进入打包/安装链路（构建产物包含），zip 契约（character 子目录、webp 白名单）合规
- [ ] 三表情触发时实际播放新素材动画（非降级路径）
- [ ] 通过 `npm run build` 与 `npm run verify`

## 评论

（来源：PRD 实现决策 8；ADR-0009。素材为美术产出——若素材由外部制作，本工单即接收/入库/验收；素材规格详见 `docs/animation-inventory.md`。）
