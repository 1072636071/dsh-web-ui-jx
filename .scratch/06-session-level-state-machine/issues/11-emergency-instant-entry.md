# 11 — 紧急态即达：入场跳过过渡段直接 cross-fade 落循环态

**Status:** ready-for-human

**构建内容：** permission/error 的可读性增强。当前硬切语义只是「立即开始播过渡」，而过渡段经 idle 中转两段串联约 7s（单段实测 3484ms）后才落到目标循环态——紧急事件的**状态身份**迟迟不可读。增强方案：紧急态（permission/error）入场跳过过渡段，复用焦点切换的 150ms 淡入淡出 cross-fade 直接落循环态（「秒达可读」）；退场保留现有过渡段（permission 造型的退场过渡本身有叙事价值）。

**背景权衡（grill 会话决策记录）：**

- 2026-08 grill 会话中用户选定先修主犯（issue 08 结构等价门槛），本增强**缓议**，留待人工决定是否立项。
- 若实施：需与 issue 09/10 的遮蔽修复协同验证「紧急态秒达」端到端成立。

**验收标准（若立项）：**

- [ ] 焦点会话进入 permission/error 时浮层 150ms 内呈现目标循环态（无过渡段）
- [ ] 紧急态消退退场仍播现有过渡段序列
- [ ] reduced-motion 下直接切换无淡入淡出
- [ ] 纯逻辑测试覆盖紧急入场计划构造
- [ ] 通过 `npm run build` 与 `npm run verify`
