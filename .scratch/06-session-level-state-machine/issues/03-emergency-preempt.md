# 03 — 紧急抢焦与交还

**Status:** ready-for-agent

**Blocked by:** 02

**构建内容：** 后台会话需要用户注意时浮层主动提醒。非焦点会话出错（error）或请求授权（permission）时，浮层自动切到该会话；事件消退后自动交还焦点给用户打开着的会话；用户手动点击会话气泡切换后，焦点保留手动选择，紧急事件不再覆盖。

**验收标准：**

- [ ] 非焦点会话进入 error（hasError）时浮层抢焦切换过去
- [ ] 非焦点会话进入 permission（pending）时浮层抢焦切换过去
- [ ] 其他非焦点事件（thinking/reading/replying/working/done/idle）不抢焦
- [ ] 紧急事件消退（会话回到非紧急态）后，焦点自动交还当前打开会话
- [ ] 用户手动切换焦点（点击会话气泡）后，紧急事件不覆盖手动选择；直到用户再次手动切换
- [ ] 抢焦与交还过程中的画面切换遵循焦点切换规则（直接切 + 淡入淡出）
- [ ] 纯逻辑测试覆盖：抢焦触发、交还触发、手动保留、消退与抢焦并发时序
- [ ] 通过 `npm run build` 与 `npm run verify`
