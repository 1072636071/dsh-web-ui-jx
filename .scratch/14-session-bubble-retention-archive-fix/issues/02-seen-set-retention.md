# 完成见闻集：未点开的完成气泡跨刷新留存

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** bug 1 完整闭环——凡观察到的完成气泡（含从未点开的）在页面刷新后持续可见，「哪些任务还没处理」的提醒不再因刷新蒸发。退场路径不变：手柄/Delete 收起（可逆、跨刷新保持隐藏）、宿主归档（不可逆）；会话再次完成时旧的收起记忆自动解除、重新提醒。

方案要点（ADR-0028 决策 1）：客户端持久「完成见闻集」——SDK 的 completed 位是连接内活事实、刷新即失忆，跨刷新留存必须客户端自己记账。

**验收标准：**

- [ ] 新增持久见闻集存储实例（复用既有 id 集合工厂与命名轨），容错对齐既有纪律：读失败/形状不符回落空集、写失败静默仅本次会话生效
- [ ] 组件层观察到条目完成态即提交记账（幂等，无需上一帧对照表）；点击跳转的既有保留记账路径零变化
- [ ] 投影入选范围扩展：running / completed / 保留记账 / 见闻集任一命中即可见；收起与归档的隐藏优先于一切入选；运行中/等待交互豁免规则原样保留
- [ ] 总开关关闭时见闻集不参与投影（回到 SDK 原生瞬态语义），开启时恢复
- [ ] 端到端验证：任务完成出现气泡（不点开）→ 刷新 → 气泡仍在；手柄收起 → 刷新 → 保持隐藏；新一轮完成上升沿重新弹出
- [ ] 纯逻辑逐条目比对测试覆盖新入选/优先级/豁免矩阵；存储层容错测试对齐既有 localStorage 存取测试模式
- [ ] 全量测试通过；`npm run build` + `npm run verify` 验收通过
