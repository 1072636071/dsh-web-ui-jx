# 02 — 变体素材转码（绿幕视频 → 一次性 webp）与三道质检门

**Status:** resolved

**Blocked by:** 无——素材已由用户提供（Downloads 9 段，采纳 6 段）

**构建内容：** `tools/` 新增视频转码脚本（imageio-ffmpeg 解码 + Pillow 处理）：去绿幕（色度键 + 边缘去溢色）、擦除右下角「千问AI生成」水印（底部亮色低饱和文字块自动检测）、抽帧重定时到 67ms/帧、降采样 360×640、编码为只播一遍的动画 webp（`loops=1`）。采纳映射：待机-张望→`idle-v2`、待机-舒展→`idle-v3`、待机-整理饰物→`idle-v4`、工作-画圈→`working-v2`、工作-画横→`working-v3`、工作-来回→`working-v4`；小圈/画弧/画V 后备。转码逐段过三道质检门：（a）工作变体符咒全程在场（金色像素追踪）、（b）局部突变扫描（block-max 相邻帧差，防嵌入硬弹出）、（c）首尾帧 vs 主素材中性帧姿态复验（像素差阈值 + 目检）。不过门即弃用换后备。

**验收标准：**

- [ ] 6 个变体 webp 入 `assets/character/`，360×640、67ms/帧、`loops=1`（播一遍）
- [ ] 变体透明无底、无绿幕残留（边缘无明显绿边）、水印已擦除
- [ ] 工作 3 段符咒全程在场；全部 6 段无硬弹出突变；首尾帧与主素材中性帧姿态一致
- [ ] 单段体积合理（≤3MB），全部进 git
- [ ] 脚本可复用（后续同类素材一条命令转码）
- [ ] `npm run build` 与 `npm run verify` 通过
