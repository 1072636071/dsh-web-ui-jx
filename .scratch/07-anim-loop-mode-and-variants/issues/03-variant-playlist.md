# 03 — 运行期变体播放列表（配置 + 推进 + 随机调度 + 段间停顿）

**Status:** resolved

**Blocked by:** 02（变体素材入库后才有 URL 可配置）

**构建内容：** 状态机/runtime 支持变体轮换（ADR-0013）。要点：
1. 「状态 → 变体 URL 列表」配置（idle/working 各 3 段，主素材作为基础候选入池），后续扩态只改配置。
2. 播放项新增「循环一次」类型（一次性变体素材）；推进复用既有「播一遍 + webp 真实时长」链路；段间在中性帧停顿 ~400ms 再接下一段。
3. 调度：随机抽取、不连续重复；随机源可注入（测试可控）。
4. 进入 idle/working 时直接随机抽变体起播（过渡段已落在中性姿，帧级衔接）。
5. 打断语义：摸鱼彩蛋/poke/紧急态/状态切换打断时丢弃播放列表位置，回落后重新随机抽取（不续播半截）。
6. 仅当轮换开关开启（工单 04）且该状态有变体配置时启用；否则回退现状单一循环。

**验收标准：**

- [ ] idle/working 长驻期间可见不同动作轮换，段间衔接无跳变（中性帧停顿吃掉像素残差）
- [ ] 同一变体不连续出现；随机源注入后序列可复现
- [ ] 变体播完按真实时长推进（webp-duration 解析），解析失败回退兜底时长不冻结
- [ ] 状态切换/彩蛋/poke 打断后回落重新抽取，不续播半截
- [ ] 开关关闭或无变体配置时行为与现状完全一致（单一循环）
- [ ] 并行驻留 working 期间变体照常轮换
- [ ] 纯逻辑可单测（不依赖 DOM）；`npm run build` 与 `npm run verify` 通过
