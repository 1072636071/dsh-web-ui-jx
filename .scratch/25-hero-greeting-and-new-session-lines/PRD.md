# PRD：个性化问候 + 姜晓新建会话台词 + 全量颜文字

**Status:** ready-for-agent

## 问题陈述

用户希望三点关怀性个性化，且明确全部落在本插件：

1. 新会话空态的大标题还是宿主的「探索未至之境」——想要按时段 + 用户名的问候语（上午好 / 下午好 / 晚上好 / 该休息了）。
2. 姜晓没有「新建会话」的台词——打开一个空会话时角色毫无反应，缺仪式感。
3. 姜晓现有 12 条台词全是纯文字——想要颜文字增加表情。

这些是角色资产与个人偏好，住在角色插件里才对；宿主只该提供挂载点（见宿主侧前置 PRD）。

## 解决方案

- 插件占用宿主新开的 hero 标题 slot：按时段 + 用户名渲染问候语；未填名字时自动退化为不带名的问候；插件卸载自动回落宿主原文案。
- 姜晓在用户切到一个空会话时，说一句与时段匹配的问候台词（4 句）。
- 全部现有台词（8 条状态 + 4 条惊吓池）句尾加线条型冷感颜文字。
- 设置卡新增「个性化问候」分区：用户名输入 + 开关。

## 用户故事

1. 作为用户，我想让新会话大标题按时段显示问候（上午 5 点起 / 下午 12 点起 / 晚上 6 点起 / 23 点起「该休息了」），以便一天中任何时候都被恰到好处地招呼。
2. 作为用户，我想让问候语带上我自己填的名字，以便感到被称呼而不是被泛泛问候。
3. 作为还没填名字的用户，我想看到去掉名字与逗号但保留问候本身的文案，以便零配置也立刻有关怀感。
4. 作为用户，我想在设置卡填写并随时修改我的名字，以便称呼符合我的心意。
5. 作为手滑填长的用户，我想让超过 16 字的名字被拒绝并提示，以便大标题排版不被破坏。
6. 作为不喜欢个性化的用户，我想通过设置卡开关整体关闭问候（回落宿主原文案），以便不必为关问候而禁掉整个姜晓。
7. 作为远端浏览器（宿主 settings memory 模式）用户，我想让名字照常可用，以便功能不因环境降级。
8. 作为用户，我想让姜晓在我打开一个空会话时说一句与时段匹配的问候，以便新会话有仪式感。
9. 作为用户，我不想在姜晓的台词里看到我的用户名，以便保持「大人」的古风人设。
10. 作为深夜还在使用的用户，我想在 23 点后看到「该休息了，让我来做吧」与姜晓的劝休台词，以便被温柔提醒。
11. 作为用户，我想让姜晓全部 12 条现有台词带上线条型颜文字，以便角色更有表情。
12. 作为用户，我想让惊吓台词池保持随机惊喜，颜文字也随机搭配，以便连点不腻。
13. 作为卸载插件的用户，我想让大标题自动回落「探索未至之境」，以便无任何残留。
14. 作为维护者，我想让全部台词与颜文字集中在一处维护，以便批量修改不动渲染逻辑。

## 实现决策

- **slot 占用**：占用宿主 `conversation.hero.headline`（single/root）。**前置依赖：宿主仓库 tracker 03 号 PRD（开槽）先合入**；本插件为此新增对宿主 conversation UI 包的 peerDependency——这是 ADR-0001「独立插件」定位的一次显式破口，理由与被否决的 DOM 劫持方案见 ADR-0033。
- **时段四档**：上午 05:00–11:59 / 下午 12:00–17:59 / 晚上 18:00–22:59 / 该休息 23:00–04:59；判定为 wrap-around（`h >= 23 || h < 5`）。时区取浏览器本地时间。挂载时计算一次，不挂 timer（新建会话会重新挂载，本身即刷新时机）。
- **文案结构**：带名 / 不带名是两套完整文案（共 8 句 zh），绝不跨 key 拼接句子。本插件为中文单语，不新增英文文案；宿主 fallback 文案不动。
- **用户名持久化**：经 `createPersistentSetting`（localStorage），键名进 `STORAGE_KEYS` 单点，与皮肤/特效开关同构。不走宿主 settings 分节——memory 模式下宿主 settings 不可写，localStorage 顺带绕开该问题（ADR-0036）。校验：trim 后非空有效、上限 16 字符、剥离控制字符与换行。
- **开关**：设置卡「个性化问候」分区，默认开；关闭后 hero 回落宿主 fallback，姜晓新建会话台词一并静默（ADR-0036 附带决策）。
- **姜晓称呼**：台词一律「大人」，不带入用户名（ADR-0034）。
- **新建会话判定**：订阅 sessions 列表快照——当前会话 id **变化**且该会话为空日志（`SessionSummary.blank`）时触发一次；同一 id 不重复（记 lastGreetedId）；挂载时若当前已是空会话，补触发一次。**已知漏检（已接受）**：宿主「New Session reuses a blank one targeting the same workspace」——复用同工作区已有空白会话时 id 不变，不触发；此时 hero 也未重新挂载，行为一致。
- **台词与颜文字**：全部集中在我们现有的台词决策器里——状态台词 8 条、惊吓池 4 条句尾加颜文字；新增新建会话台词 4 句（按时段映射，惊吓池的随机机制不变）。定稿文案以 `docs/memorial/017` 的「台词草案」表为准，实施时逐字照抄（台词文案归用户，不属于代码审查范围）。
- **气泡宽度**：放宽以容纳颜文字；「一句 12 字内为佳」约束只计汉字。
- **颜文字风格**：线条型冷感（`(・∀・)` `(￣▽￣)` `(¬_¬)` `(ﾟДﾟ)` 等），避开圆润可爱型，守 `docs/character-lines.md` 的「不甜腻、不卑微」红线。

## 测试决策

- **台词决策器（纯逻辑）**：时段四档全部边界（4/5、11/12、17/18、22/23 点）与 wrap-around；带名/不带名退化；新建会话触发的 id 变化 / blank 翻转 / 同 id 不重复 / 挂载补触发。先例：现有 overlay-speech 纯逻辑测试（random 注入可控）。
- **设置**：名字校验（trim、长度上限、控制字符剥离）、开关回落行为。先例：现有 createPersistentSetting 与设置卡的测试。
- **渲染**：占用 slot 后 hero 显示时段问候、无名字时显示退化文案、开关关闭或插件缺席回落宿主文案；台词气泡含颜文字不破坏单行布局。先例：现有 CharacterOverlay / 设置卡组件测试。
- **不测**：颜文字具体字符本身（文案归用户）；宿主 slot 的声明（宿主侧 PRD 覆盖）。
