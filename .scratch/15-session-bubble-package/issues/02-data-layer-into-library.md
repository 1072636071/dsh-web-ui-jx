# 02 — 数据层迁移入库

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** 气泡列的数据核心（归组引擎、拖拽判定矩阵、标题推导、SDK 快照投影）从根插件迁入库并作为公共 API 导出；根插件改从库 import 数据层。功能上用户无感知（行为完全一致），但对开发者而言，库已是可单独消费的数据包。

**验收标准：**

- [ ] 库导出归组引擎、标题推导、相关类型与投影函数，类型完整
- [ ] 数据层相关测试全部迁入库并全绿（断言语义零改动）
- [ ] 根插件数据层代码移除，改为从库 import，根插件构建通过
- [ ] 根插件测试在改 import 后全量通过
