# PRD — 会话气泡悬浮详情窗（书页卡片）

- Feature: `16-session-bubble-hover-detail`
- Status: `completed`（2026-08-27，工单 01–05 全部 resolved；全量测试 497 绿、build/verify 21 项绿；人工视觉/实装验证见工单 05 待办）
- Source: memorial 015 `docs/memorial/015-session-bubble-hover-detail/`（Q1 用户拍板 + Q2 视觉 + 授权自行决策 D3–D8）+ ADR-0030

## 问题陈述

DSH 宿主用户把鼠标悬停到会话气泡上时，只能看到标题 + 状态点——想了解某个会话
"在聊什么"必须切换进去。多会话并行时（跑工具、子代理、多任务），用户需要
**不切换会话**就能快速预览每个气泡背后的内容：会话标题、AI 总结的一句话动态、
最后一条用户说了什么、模型最后回了什么。同时，用户想要一个可配置 API 的 AI
动态标题（用自己配的大模型 endpoint），但浏览器直连外部 LLM API 撞 CORS、API
key 明文存 localStorage 不安全——"配置 API"落地需要宿主侧代理。

气泡列还将独立成库（15-session-bubble-package），详情窗必须随之进入气泡库，
让本插件与薄壳插件同构获得。

## 解决方案

会话气泡 hover 时展开**书页卡片**详情窗（扉页式）：会话标题（书眉）→ AI 动态
标题（副题，带朱砂章点缀）→ 最后一条用户消息 → 最后一条模型消息，正文 3 行
截断，多余省略。

- **数据**：非 current 会话经 `session.history` RPC 拉尾页（纯读取、不启动 Agent、
  不改 current），提取最后用户/助手消息；模块级缓存（TTL + 会话更新失效 +
  in-flight 去重）；current 会话实施时可走对话快照实时订阅作优化。
- **AI 动态标题**：host 半区 Node 直连用户 endpoint（OpenAI 兼容协议），
  endpoint/model/频率存宿主 `settings` 分节、API key 存 `credentials`
  （引用/值分离、每操作解析、换 key 零重启）；触发重刷 = 事件驱动失效 + 悬停时
  缓存过期才生成 + 可配节流间隔。
- **库化**：详情窗全部进气泡库 `dsh-session-bubble`，数据/AI 标题走 transport
  抽象（库侧接口稳定，DSH 默认实现），本插件与薄壳插件自动获得。

## 用户故事

1. 作为 DSH 宿主用户，我想要鼠标悬停到任意会话气泡上出现详情窗，以便不切换会话就能预览这个会话在聊什么。
2. 作为 DSH 宿主用户，我想要详情窗顶部显示会话标题，以便一眼认出是哪个会话。
3. 作为 DSH 宿主用户，我想要标题下方有一行 AI 分析的动态标题（一句话描述这个会话在做什么/进展如何），以便快速把握会话当前状态。
4. 作为 DSH 宿主用户，我想要动态标题下方显示最后一条用户消息，以便知道用户最近一次说了什么。
5. 作为 DSH 宿主用户，我想要再下一行显示模型最新动态（最后一条模型消息），以便知道模型最后回了什么。
6. 作为 DSH 宿主用户，我想要各消息只显示前部分、超长截断加省略号，以便详情窗保持紧凑不撑爆。
7. 作为 DSH 宿主用户，我想要详情窗像一页书（纸感背景、书眉区、金书脊线、正文排版），以便视觉与唐风浮层体系一致且赏心悦目。
8. 作为 DSH 宿主用户，我想要悬停有短暂延迟（约 300ms）才弹出，以便鼠标掠过气泡时不误触。
9. 作为 DSH 宿主用户，我想要移开后延迟隐藏（约 200ms），以便我能把鼠标移进详情窗内操作而不闪烁。
10. 作为 DSH 宿主用户，我想要详情窗内可点击跳转到对应会话，以便从预览直接进入会话。
11. 作为 DSH 宿主用户，我想要详情窗在深浅主题下都有合适的纸感配色，以便在两种主题下都清晰可读。
12. 作为 DSH 宿主用户，我想要 AI 动态标题的大模型 API 可配置（endpoint、模型、API key、重刷频率），以便用我自己选的模型服务。
13. 作为 DSH 宿主用户，我想要 API key 不落在浏览器端（存宿主凭据体系），以便配置安全。
14. 作为 DSH 宿主用户，我想要动态标题在会话有更新时自动失效、下次悬停时重新生成（并受频率节流约束），以便标题始终大致反映会话现状又不频繁烧 token。
15. 作为 DSH 宿主用户，我想要未配置 AI API 时不显示动态标题（不占位不报错），以便没有模型配置也能正常用详情窗。
16. 作为 DSH 宿主用户，我想要触屏设备上长按气泡也能触发详情窗，以便不依赖鼠标也能使用。
17. 作为 DSH 宿主用户，我想要详情窗贴近气泡展开、接近视口边缘时自动换侧，以便任何位置的气泡都完整可见。
18. 作为 DSH 宿主用户，我想要加载中显示轻量骨架/占位、失败静默降级，以便网络抖动时不产生刺眼报错。
19. 作为 DSH 宿主用户，我想要同一会话的预览数据有缓存（15s TTL + 会话更新失效），以便反复悬停不重复拉取。
20. 作为开发者，我想要预览提取、刷新判定、提示词组装全部是零依赖纯函数（复用会话气泡纯逻辑 seam），以便 vitest node 单元测试。
21. 作为开发者，我想要详情窗的数据获取与 AI 标题通过 transport 接口抽象（默认 DSH 实现），以便未来可换实现、便于测试替身。
22. 作为开发者，我想要详情窗全部进气泡库 `dsh-session-bubble`，以便本插件与薄壳插件共享同一实现、自动获得该功能。
23. 作为维护者，我想要视觉遵循 DESIGN.md（深底浅字、装饰克制、金/朱砂/墨阶 token），以便与既有体系不打架。

## 实现决策

> 全部决策来自 memorial 015 grill（Q1 用户拍板 host 直连、Q2 用户拍板书页卡片意象、D3–D8 授权助手定案）与 ADR-0030。以下不含文件路径；模块名即领域词汇。

### AI 动态标题

- **D1 — host 半区 Node 直连用户 endpoint**（OpenAI 兼容协议）：库定义
  `DynamicTitleTransport` 接口（`generateTitle(request) → string`），默认实现经
  host 半区路由（`/api/dsh-jx/ai-title`，`webServer.register`）由 Node 侧 fetch
  用户配置的 endpoint；客户端只传消息上下文（标题 + 最后消息），不触 key。
- **D2 — 配置复用宿主原生体系**：endpoint/model/重刷频率注册宿主 `settings`
  分节（免费获得宿主 Web UI 设置页）；API key 存 `credentials`
  （`ctx.credentials`，引用/值分离、每操作解析、换 key 零重启）。本插件
  SettingsCard 加快捷入口；薄壳插件注册同名 settings 分节（保持最小化，不
  自定义设置 UI）。
- **D3 — 触发重刷 = 事件驱动失效 + 悬停时缓存过期才生成**：会话有更新（列表
  updatedAt/消息变化）标记动态标题缓存脏；悬停时若脏或 TTL 过期则生成；生成间
  可配最小节流间隔；平时不轮询。

### 数据获取

- **D4 — 非 current 会话用 `session.history` RPC 拉尾页**（`maxMessages` 取少量，
  纯读取不启动 Agent、不改 current，尾页含 in-flight partial 可作"正在生成"
  动态）；模块级缓存 `Map<sessionId, {preview, fetchedAt}>` + TTL（默认 15s）+
  会话列表 `updatedAt` 变化失效 + in-flight 去重（同会话并发悬停只发一次）。
  current 会话实施时可用对话快照实时订阅作优化。

### 交互

- **D5 — hover 300ms 进入 / 200ms 离开**（防误触、可移入详情窗）；详情窗贴气泡
  展开、视口越界自适应换侧；触屏（pointer:coarse）长按 500ms 触发；详情窗内
  点击 `sessions.open` 跳转；hover 期间气泡 hover 态保持不闪烁。

### 截断

- **D6 — 消息正文 3 行 `line-clamp` 截断 + 省略号**，另加字符级护栏（防无空格
  超长串撑爆）；行数可配置。

### 范围与库化

- **D7 — 详情窗全部进气泡库 `dsh-session-bubble`**：`SessionBubbleDetail` 组件 +
  纯逻辑（预览提取/刷新判定/提示词组装）+ 样式 + token 扩展；数据获取走库的
  `transport` 抽象（默认 DSH 实现用 `connection.api`）；本插件与薄壳插件消费
  同一库自动获得。

### 视觉（书页卡片）

- **D8 — 书页卡片 token**：新增 `--jx-paper-bg`（纸感背景，深色=古褐纸、
  浅色=米白）与 `--jx-paper-edge`（纸边光）进 `bubble-theme.css`（深浅双值随
  主题切换）；左侧 2px 金线书脊（`--jx-gold`）；AI 动态标题前置小朱砂章点缀
  （`--jx-seal`，克制使用）；顶部书眉区标题 + 动态副题排版；正文 3 行截断。
  遵守 DESIGN.md 深底浅字/装饰克制纪律。

### 模块（seam）

| 模块 | 改动 | 性质 |
| --- | --- | --- |
| 详情窗纯逻辑（预览提取/刷新判定/提示词组装） | 新增，与归组引擎同住纯逻辑层，零依赖导出 | **复用既有纯逻辑 seam**（新 seam 数 = 0） |
| 数据获取 transport | 库接口 + DSH 默认实现（`connection.api`） | 新增接口（接线非测试 seam） |
| 动态标题 transport | 库接口 + host 半区默认实现 | 新增接口（接线非测试 seam） |
| `SessionBubbleDetail` 组件 | 新增，消费纯逻辑 + transport | DOM 薄壳 |
| 书页卡片样式 + token | 新增，扩展 `bubble-theme.css` | 新增 token（视觉） |
| host 半区路由 | 新增 `ai-title` 路由 + settings/credentials 接线 | host 接线 |

## 测试决策

- **好测试的定义**：只测外部行为（输入：history 事件序列 / 缓存状态 / 配置 →
  输出：预览结构 / 是否应刷新 / 提示词文本），不测 DOM、类名、React 渲染、
  transport 网络时序。
- **Seam：复用既有纯逻辑 seam**（气泡库纯逻辑层 + vitest node 环境，先例：
  归组引擎/投影/保留记账测试同款模式）。**新 seam 数 = 0**。
- **被测模块**：
  - 预览提取：给定 `history` 尾页事件序列（含 user/assistant/tool 事件、空日志、
    纯工具尾、in-flight partial），断言最后用户消息/最后助手消息提取正确、
    空与异常输入回退为空。
  - 刷新判定：给定 `{lastGeneratedAt, dirty, ttl, minInterval}`，断言脏/TTL
    过期触发、节流间隔内抑制、未配 API 短路。
  - 提示词组装：给定标题 + 最后消息，断言产出提示词含关键上下文且长度有界。
- **不自动化部分**：hover 延迟/触屏长按、书页视觉、换侧、骨架/降级展示——人工
  视觉验证，沿用浮层系统一贯惯例（09 号功能测试决策同款）。
- **质量门槛**：typecheck + 全量测试通过后，根插件 `npm run build` +
  `npm run verify`（AGENTS.md 构建验收约束）。

## 超出范围

- **注册 LLM adapter 走宿主模型体系**：已否决（ADR-0030），保留为未来演进方向
  （打通宿主模型目录/发现）。
- **详情窗内完整对话浏览/滚动**：只显示最后用户消息与最后模型消息两行预览，
  不提供会话内翻页。
- **完整主题系统**：只新增纸感/书脊/朱砂章 token，`--dsw-*` 依赖宿主。
- **无障碍大改**（键盘/读屏全覆盖）：本期鼠标 + 触屏长按为主，键盘可操作作
  低成本补充（按钮语义），不铺开。
- **薄壳插件自定义设置 UI**：沿用库注册的宿主 settings 分节，不做自有表单。
- **动态标题的语言/风格可配**：本期仅 API 配置 + 频率，prompt 固定模板。

## 补充说明

- **单一事实源**：详情窗进气泡库（D7），本插件与薄壳插件自动获得，与 15 号
  spec（独立成包）衔接——建议 16 在 15 的库剥离完成后实施。
- **数据源确认**：`session.history` 为宿主 apiproxy 既有 RPC，官方文档（会话
  日志：可回放事实源）确认纯读取、不启动 Agent；客户端经 `connection.api`
  调用（无需宿主改造）。
- **配置安全**：key 走 `credentials`（引用/值分离），endpoint/model 走
  `settings`，浏览器端零 key 暴露；host 侧 fetch 无 CORS。
- **触发语义**：动态标题"事件失效 + 悬停生成 + 节流"避免常驻轮询烧 token；
  未配 API 时整行隐藏。
- **来源链**：朋友诉求（2026-08-27）→ memorial 015 grill（Q1 形态 / Q2 视觉 /
  D3–D8 授权定案）→ ADR-0030 → 本 PRD。
