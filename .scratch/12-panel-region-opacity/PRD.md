# PRD — 面板区域独立不透明度滑块

**Status**: ready-for-agent
**来源**: memorial `011-panel-opacity-per-part`（grill 定案，ADR-0025 已回写）；欢迎背景壁纸层延续（ADR-0024）
**创建**: 2026-08-25

## 问题陈述

ADR-0024 的欢迎背景壁纸层落地后，面板半透明由**单一全局值** `--jx-panel-alpha` 统一驱动——`--jx-surface-0..3` 全部消费它，宿主经 `--dsw-*` remap 后所有面板同步半透明。用户希望**面板的各个部分各自有独立的不透明度滑块**，以便更精细地控制每块面板露出壁纸的程度（例如让侧栏透出壁纸、而输入区保持更实、反之亦然）。

现状一个全局值只能整体调，无法按面板分区。此外调研发现既有 remap 命名 bug：插件把侧栏变量 remap 成 `sidebar-bg`，宿主真名是 `sidebar-fill`，导致**宿主侧栏从未被皮肤化/可半透明**；`assistant-bubble` 映射宿主根本不存在（死代码）。

## 解决方案

在欢迎背景开启时，把面板不透明度从"一个全局值"拆成 **「未拆分面板」全局值 + 五个按区域独立值**：

- **可独立区域**（宿主 `--dsw-specific-*` 支持单独 remap）：左侧导航列/文件树、底部输入栏（composer）、用户消息气泡、目标/Todo/Queue 卡片、composer 附件钮。
- 每个区域一个专属 alpha 变量、一个滑动条（0–100%）；「其余面板」全局值控制会话区/顶栏/右详情列等未拆分面板。
- **这些区域的半透明只在「欢迎背景」开启时生效**：关闭背景即移除对应变量、区域回不透明，保持"背景关=纯色"闭环。
- 顺带修复侧栏 remap 真名、删除无效的 assistant-bubble 映射。

## 用户故事

1. 作为用户，我希望「左侧导航列/文件树」有一根独立的不透明度滑块，以便单独决定这块面板露出壁纸的程度。
2. 作为用户，我希望「底部输入栏（composer）」有一根独立滑块，以便壁纸背景下输入区可读性与通透度平衡。
3. 作为用户，我希望「用户消息气泡」有一根独立滑块，以便气泡与背景的层次感可控。
4. 作为用户，我希望「目标/Todo/Queue 卡片」有一根独立滑块，以便这三张任务卡片统一调整（共用宿主 tip 变量，三卡联动）。
5. 作为用户，我希望「composer 附件钮」有一根独立滑块，以便工具控件与编辑器主体分开调节。
6. 作为用户，我希望保留一个「其余面板」全局滑块（会话区/顶栏/右详情列等），以便未被细分拆分的面板仍可统一调节。
7. 作为用户，我希望各滑块在「欢迎背景」总开关关闭时置灰禁用，且这些面板恢复不透明（与现有"背景关=纯色"一致）。
8. 作为用户，我希望每个滑块的值持久化（刷新不丢），并像现有壁纸/压暗滑块一样即时生效。
9. 作为用户，我希望修复后的侧栏真正被 "唐风皮肤 + 半透明" 覆盖，以便整页观感一致（当前侧栏从未被皮肤化）。
10. 作为用户，我希望深色（墨金卷轴）与浅色（宣纸梅花）两主题下，各区域滑块的基准色都正确（深/浅各自对应 surface 色）。

## 实现决策

- **token 模型**：保留 `--jx-surface-0..3`（消费全局 `--jx-panel-alpha`）作为**未拆分面板**的兜底；另为五个可独立区新增专属 alpha 变量 `--jx-panel-{sidebar,input,bubble,tip,selector}-alpha`（深/浅主题各定义基准 RGB）。区域变量**独立覆盖**，不与全局相乘。
- **host remap 修正**：`--dsw-specific-sidebar-fill`（修 `sidebar-bg`→`sidebar-fill`）、`--dsw-specific-input-major`、`--dsw-specific-bubble`、`--dsw-specific-tip`、`--dsw-specific-selector` 分别 remap 到对应区域色 + 区域 alpha；删除无效的 `--dsw-specific-assistant-bubble`。
- **配置**：在欢迎背景配置模块新增五个持久化项（沿用 `localStorage('jx-*')` + 钳制 0–100 + 订阅通知的既有模式），默认值 50。
- **运行时**：`startWelcomeBackdrop` 的同步逻辑在「背景开」时把五个区域 alpha 写为 body CSS 变量，「背景关」时移除（区域回实色）。
- **UI**：设置卡皮肤 section「面板不透明度」分组，值为「其余面板」全局 + 五根区域滑块；总开关关闭时全部禁用置灰。
- 复用既有 seam：欢迎背景配置模块与运行时同步模块（不新建重复的状态管理）。

## 测试决策

- **高层 seam**：欢迎背景配置模块（localStorage 读写/钳制/订阅）与运行时同步（写/移 body CSS 变量）。沿用既有 `tests/client/welcome-backdrop.test.ts`（jsdom）先例。
- 好测试描述：只断言外部可观察行为——`get/set` 读写与钳制一致、订阅通知次数、背景开关切换时各区域 CSS 变量正确写入/移除、默认值。
- 新增断言：五个区域变量各随对应 setter 写入正确 alpha、且背景关时全部移除；不做实现细节依赖。

## 超出范围

- **会话区 / 顶栏 / 右详情列** 独立拆分（宿主用 `--dsw-alias-bg-base`，需按列二次 remap）——二期。
- **modal / 设置抽屉面板体 / 菜单** 独立拆分（`layer-2`/`layer-3` 层级绑定）——保持按表面层级。
- **目标/Todo/Queue 三卡分开控制**（宿主共用一个 `tip` 变量，需宿主拆分 token）——暂不推进。
- 无壁纸场景下面板区域的新型状态机或动画。

## 补充说明

- 修 `sidebar-fill` 后，宿主侧栏首度被皮肤化：**无壁纸时**侧栏由宿主 bluish 底色变为 jx surface 观感，属预期而非回归。
- 区域 alpha 在背景关闭时对面板无效（回实色），与"壁纸淡影纯透明"场景一致。
- 五组默认均 50，使首次开启壁纸时观感与现状全局面板默认一致。
