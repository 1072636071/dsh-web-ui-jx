# PRD — 会话气泡单击保留 + 拖拽收纳双投放区

Status: resolved
来源：memorial 010（grill 定案 2026-02-14，ADR-0022 已同步全局 `docs/adr/`）

## 问题陈述

用户看到某会话任务完成 → 点击姜晓左侧气泡列的对应气泡过去查看 → 但并没有继续处理该任务 → 气泡已经消失（SDK 的"完成提醒"位在会话被打开时即被清除）→ 事后忘记了哪些会话还需要自己处理。

「查看」和「办结」被强制绑定为同一动作，缺少「看过但未办结」的中间态。同时，办结的会话堆积在侧边栏里，用户希望有一种一次手势把它们收纳掉的办法——但插件能力范围内没有真删除，最重的合法操作是归档（隐藏、日志保留、不可逆）。

## 解决方案

设置卡新增两个开关。打开「查看后保留气泡」后：单击气泡照旧跳转，但气泡保留在列中，直到用户明确处置它——把它**拖进「收起区」**（近放：暂时隐藏提醒，可逆），或**拖进「归档区」**（远放、警示样式：真归档，气泡与侧边栏同时清爽，不可逆）。运行中和等待交互的气泡不可拖走；归档区拒绝当前正停留的会话。关闭总开关即完全回到现状（点击即跳转、看完即消失）。

## 用户故事

1. 作为用户，我想要单击会话气泡后跳转到该会话且气泡保留在列中，以便我看完后不会忘记哪些会话还需要处理。
2. 作为用户，我想要把看过但不急的气泡拖到收起区暂时隐藏提醒，以便不被打扰且将来仍可从侧边栏找回。
3. 作为用户，我想要把彻底办结的会话气泡拖到归档区一次性归档，以便气泡列和侧边栏同时清爽。
4. 作为用户，我想要在设置卡里开关「查看后保留气泡」，以便随时回到旧行为（点击即跳转即消失）。
5. 作为用户，我想要在设置卡里单独开关「拖拽归档」，以便不想要不可逆操作时只保留轻量收起区。
6. 作为用户，我想要保留与收起的记账跨页面刷新依然有效，以便待办记忆不因重开浏览器丢失。
7. 作为用户，我想要运行中（金呼吸点）和等待交互（朱砂描边）的气泡无法被拖走，以便不错过正在跑的任务与待审批事项。
8. 作为用户，我想要归档区远离收起区并带警示视觉，以便手滑也几乎不可能误入不可逆操作。
9. 作为用户，我想要悬停归档区时看到「归档后从列表隐藏，不可恢复」提示，以便投放前知道后果。
10. 作为用户，我想要当前正停留的会话被禁止拖入归档区，以免归档导致我的视图突然跳到新建会话页。
11. 作为用户，我想要用 Delete / Backspace 收起键盘聚焦的气泡，以便无鼠标场景下仍可管理提醒列表。
12. 作为用户，我想要拖动时气泡跟随指针、松手未落入投放区时弹回原位，以便取消是自然动作。
13. 作为用户，我想要收起过的会话再次完成新一轮任务时重新出现在气泡列，以便旧的"暂时不想看"不会吞掉新的完成提醒。
14. 作为用户，我想要已归档的会话彻底不再出现在气泡列（即使本地还记着它），以便归档是真正的终点而非又一层过滤。
15. 作为用户，我想要在气泡上按下拖动时角色浮层整体不跟着跑，以便两种拖拽语义互不打架。
16. 作为用户，我想要气泡被移除时播放既有的淡出动效，以便视觉连续、确认操作生效。
17. 作为用户，我想让保留模式下的气泡照常计入数量上限与折叠逻辑（等待交互组仍豁免折叠永驻可见），以便列不会无限增长、紧急信号优先级不变。
18. 作为用户，我想让投放区只在保留模式开启时出现、归档区再受第二开关控制，以便界面上出现的每个东西都可解释。
19. 作为用户，我想让 Enter / Space 激活气泡仍是「跳转 + 保留」，以便键盘行为与鼠标单击一致。
20. 作为用户，我想让配置②在配置①关闭时灰显，以便主从关系一眼可见、不产生无效配置。

## 实现决策

- **可见性判定集中在既有纯逻辑 seam**：气泡投影纯函数向后兼容扩展一个可选参数（保留模式上下文：开关态 + kept 集合 + dismissed 集合 + archived 会话集合）。可见性 = `running || completed || kept` 减去 dismissed 与 archived；不传参时行为与现状逐条目一致（现有测试域基准为护栏）。集合必须进入该函数内部——其内部范围过滤硬编码 `running || completed`，kept 条目会被外部前置过滤丢弃。
- **拖拽判定矩阵为同模块新增纯函数**：输入指针位移、落点、条目标志（completed / pendingInteraction / isCurrent），输出 `click | dismiss | archive | forbidden`。位移阈值约 8px 区分点击与拖拽；running、pending 组成员一律 forbidden；当前会话 × 归档区 forbidden（规避归档清空选择的副作用）；当前会话 × 收起区允许。
- **新配置模块**（对齐既有皮肤/特效配置模块模式）：两布尔开关默认均开；kept/dismissed 集合 localStorage 持久化（`jx-bubble-keep-*` 命名轨）；读失败回落默认、写失败静默；轻量 store 供组件订阅即时生效。
- **dismissed 生命周期**：会话新一轮 completed 上升沿清除其 dismissed 记账（每次完成都是新提醒）；id 已不在宿主列表时惰性忽略并在写入时裁剪，防集合膨胀。kept 条目冗余无害，随裁剪自然清理。
- **归档权威在 SDK**：派生层从 workspaces 列表快照读 archivedSessionIds 做排除；本地不重复记账归档态。归档调用经 `workspaces.archiveSession`，失败静默（气泡不消失即为失败信号）。
- **组件接线**：气泡列组件挂 pointer 手势（pointerdown 记起点 → 超阈值进入拖动态、原气泡跟随指针 → 松手按落点解析结果）；双投放区常驻渲染——收起区近放（气泡列正下方）、归档区远放（角色脚边）警示描边 + hover 提示文案；未命中松手弹回。整盒拖动排除机制原样复用，气泡上的 pointerdown 不启动浮层拖动。
- **键盘**：Delete/Backspace 收起聚焦气泡；归档刻意不设键盘路径（危险操作保持拖拽仪式感）；aria-label 补充可拖状态与移除方式说明。
- **设置卡**：角色 section 追加两个 toggle（「查看后保留气泡」「拖拽归档会话」），复用既有 switch 样式；② 主从于①，①关时②灰显。
- **动效**：移除复用既有退出淡出机制；投放区命中反馈脉冲可选加分项；prefers-reduced-motion 照例全降级。
- **架构依据**：ADR-0022（含全部被否决替代方案：三种双击判定、三种垃圾桶语义、三种布局、三种配置切分）。

## 测试决策

- 全部测试落在**唯一 seam**：气泡纯逻辑模块及其既有测试文件（vitest node 环境、无 DOM/React，先例 = 现有 session-bubbles 行为基准测试）。
- **回归护栏**：扩展后的投影函数不传新参数时，现有全部行为基准逐条目保持绿色。
- 新增行为断言组：kept 保留已查看条目；dismissed 隐藏；archived 排除；开关联动的退化路径（总开关关 = 与现状输出全等）；running/pending 条目不受记账影响；上限折叠与 pending 豁免在新输入下语义不变。
- 拖拽判定矩阵逐格断言（含 forbidden 组合全排列：running×任意、pending×任意、当前泡×归档）。
- 不测：localStorage 配置包装（仓内同类模块均无直测先例）；组件渲染、pointer 接线、投放区视觉（仓库无 React/DOM 测试先例，由纯逻辑覆盖判定、构建验收兜底）。
- 实施后必须通过 `npm run build` + `npm run verify`（仓库构建验收约束）。

## 超出范围

- 取消归档（unarchive）：客户端契约层不存在该方法，归档错误的恢复只能依赖宿主侧手段。
- 真删除会话：会话日志为宿主持有的 durable 数据，插件层无删除权限。
- 宿主侧边栏 UI 改动：本插件 UI 面仅角色浮层 + 设置卡。
- 经侧边栏打开已完成会话时的保留记账：本次记账作用域明确为气泡点击（ADR-0022 D1）；侧边栏路径维持 SDK 原生「看完即消失」。列为潜在后续迭代（需监听 current 变化，复杂度另议）。
- 触屏长按拖拽的手感调优：pointer events 基础支持即可，不做移动端专门优化。
